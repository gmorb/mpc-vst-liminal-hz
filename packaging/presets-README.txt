My Presets are not kept in this folder any more (from Liminal Hz 1.5).

They are in the "Liminal Hz" folder at the top of this drive: Liminal Hz/presets/, one small file each (name.lhzp).
Updates replace the plugin's folder, so that folder of your own is never touched: your presets survive every update.
Liminal Hz moves any presets it finds here into it the first time it starts.

Name, load, rename and delete them from a phone: tap MY PRESETS, then NAME ON PHONE, and open the address it shows on a
phone or computer on the same Wi-Fi. You can also rename or delete a .lhzp file there from a computer; the file name is
the preset's name. After changing files by hand, press RESCAN.
