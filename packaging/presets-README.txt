My Presets: the sounds you save with SAVE in the MY PRESETS list, one small file each (name.lhzp).
This folder is yours: updating or uninstalling the plugin keeps it.

Name, load, rename and delete them from a phone: tap MY PRESETS, then NAME ON PHONE, and open the address it shows on a
phone or computer on the same Wi-Fi. You can also rename or delete a .lhzp file here from a computer; the file name is
the preset's name. After changing files by hand, press RESCAN.
